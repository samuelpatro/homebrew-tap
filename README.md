# homebrew-tap

Homebrew tap for apps by [@samuelpatro](https://github.com/samuelpatro).

```sh
brew tap samuelpatro/tap
```

| Cask | Description |
| --- | --- |
| [`vibejuice`](https://github.com/samuelpatro/vibejuice) | One-click account switcher for Claude Code, Codex CLI and Grok CLI. `brew install --cask vibejuice` |
